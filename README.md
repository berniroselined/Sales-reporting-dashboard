# AI-Assisted Distributor Sales Reporting

A portfolio project using **fictional data** (consumer goods, Southeast Asia, January to June 2026).

## What I built
- Cleaned a 300-row messy distributor sales file in Excel
- A 3-page Power BI dashboard (15 visuals, 10 DAX measures); total revenue SGD 577.81K
- An executive summary drafted with Claude, then fact-checked (about 280 words cut to about 165, unsupported recommendations removed)
- A Q&A app where the calculations run in code; tested on 5 questions, 5 correct

## Files
- `Project1_Case_Study_Final.pdf`: one-page case study with the dashboard pages
- Dashboard PDF and screenshots
- `cleaned_sales_data.xlsx`: the fictional dataset

## Limits
Small fictional dataset. The Q&A app needed a paid Claude plan for heavy use, so screenshots are included.
